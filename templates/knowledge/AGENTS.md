# Lore repository instructions

Before using this repository, read `system/OPERATING_RULES.md`. It is the
authoritative shared policy for evidence, retrieval, synthesis, and knowledge
maintenance.

## Instruction-file responsibilities

- Keep shared Lore policy in `system/OPERATING_RULES.md`; do not restate it
  here.
- Put repository-specific owner context, stricter requirements, access
  profiles, and session procedures in this file through an explicit
  maintenance change.
- Keep `CLAUDE.md` as a compatibility passthrough that imports this file and
  `system/OPERATING_RULES.md`; do not copy policy into it.
- Do not modify `system/`, `AGENTS.md`, `CLAUDE.md`, or `lore.yaml` during
  normal knowledge maintenance.

## Repository-specific additions

Place repository-specific owner context, stricter requirements, access
profiles, and session procedures below this heading. Reference rather than
repeat the shared policy.
